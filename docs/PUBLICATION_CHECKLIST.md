# Publication checklist — not a publication receipt

- User has authorized the exact account/repository destination and public visibility
- Select and apply MIT or Apache 2.0 to original code as required by the event; decide asset/data terms separately
- Scan current files AND git history for credentials, .env, SQLite files, private source links and personal material
- Exclude private_review, county geometry, actual volunteer contacts, actual colony coordinates, real WhatsApp exports and the owner's Zeus photograph unless separately authorized
- Preserve the synthetic image manifest and clarify generated images are not validated identity or clinical evidence
- Verify expected commit on remote, dependency installation, tests and actual hosted app URL
- Do not submit to the hackathon merely because code is public
